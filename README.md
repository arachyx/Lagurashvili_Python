# QA Automation Traineeship Technical Task (Python)

This repository contains my solution for the QA Automation traineeship technical task, implemented in Python with interactive console input and output.

Project Structure:

* `algorithm_task.py` — Interactive algorithm implementation for number validation (`> 7`), name checking (`"John"`), and filtering array elements that are multiples of `3`.
* `bracket_task.py` — Bracket sequence validator, error locator, and corrector for arbitrary bracket sequences (`()`, `[]`, `{}`), including the given task sequence.


```bash
python algorithm_task.py
python bracket_task.py
